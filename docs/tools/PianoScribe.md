# PianoScribe — 弹琴记录器

一个在浏览器里运行的**写谱工具**：把你想弹的旋律、和弦、乐句，先在网页上简单地按出来、记录下来，再对照着谱面去游戏里弹。无需安装，打开即用。

> PianoScribe 不是给游戏内用的（游戏监听不了键盘），而是帮你**打草稿**：在网页上即兴敲出音符，自动记录成简谱/按键谱，还能回放试听、自由编辑。有了这份谱，你就能对照着去游戏内置琴上弹奏。

## 🎯 使用场景

- **打草稿 / 写谱**：先在网页上把旋律按出来，自动记录成谱面
- **对照弹奏**：记录好后，照着谱面去游戏琴（或任何琴）上弹
- **即兴记录**：随手弹出的灵感，实时记录不丢失
- **复盘练习**：回放自己弹的内容，配合播放指示跟踪进度，反复打磨

## ✨ 核心功能

### 🎹 三组琴键，覆盖三个八度
高/中/低三个八度各 7 个音，默认键位：

| 八度 | 琴键 | 简谱 |
|------|------|------|
| 高音 | `Q W E R T Y U` | 1̇ 2̇ 3̇ 4̇ 5̇ 6̇ 7̇（数字上方加点） |
| 中音 | `A S D F G H J` | 1 2 3 4 5 6 7 |
| 低音 | `Z X C V B N M` | 1̤ 2̤ 3̤ 4̤ 5̤ 6̤ 7̤（数字下方加点） |

- **键盘或鼠标**均可弹奏，按下即发声
- 琴键按下有高亮反馈，实时显示当前音符

### 🎛 自定义键位
- 三个输入框（高音/中音/低音）依次输入 7 个字母，对应 1-7
- 改完点"应用"，琴键布局、记录、回放全部同步更新
- 支持一键"重置"恢复默认键位
- 自动校验：每行必须 7 个键位、21 个键位不重复

### 🎼 实时记录
- 弹奏的音符**即时写入谱面**，松开即完成该音
- **和弦识别**：两键在时间窗口内同时按下，自动记成上下对齐的和弦（高音在上）
- 支持 `Backspace` 退格、`Enter` 换行、`空格` 插入 `|` 小节分隔

### 🔁 自动回放
- **▶ 播放**：按顺序回放你弹奏的全部内容，和弦同时发声
- 在 `|` 分隔和换行处自动停顿，还原乐句节奏
- **延迟滑块**调节播放速度（0.1s–1.2s）
- **从指定位置播放**：可输入起始音符序号，或点选谱面音符从那里开始
- **播放指示**：蓝色高亮圈实时跟随当前音符

### ✏️ 灵活编辑
点击谱面上任意音符，即可进入编辑：
- **直接输入音高**：用 `-x`（低音）/ `x`（中音）/ `+x`（高音）表示三个八度，如 `-5`、`3`、`+1`
- **和弦编辑**：用逗号分隔多个音高（如 `+1,+3,+5`），单音 ↔ 和弦随意切换
- **插入**：在此后插入音符、`|` 分隔符
- **拆和弦**：把误判的和弦拆成独立单音
- **删除**：移除选中音符

### 🔊 悦耳音色
- 纯 Web Audio 合成，**无需采样文件、无需联网**
- 提供 **3 种音色预设**（温暖 / 柔和 / 明亮），随时切换对比

### 📂 数据管理
- **导出 / 导入 JSON**：保存和恢复完整记录（含曲名、模式、音符）
- 导出的 JSON 简洁干净，键位信息自动生成，方便手动编辑
- **复制**：一键复制谱面文本

### 🎨 界面
- 粉蓝渐变配色，高/中/低音分别用粉/蓝/紫区分
- 简谱 / 按键两种显示模式随时切换
- 智能换行：以 `|` 为段落边界，绝不裁断乐句

## 🚀 快速上手

1. 打开页面，**点一下页面或"🔊 声音"按钮**解锁音频
2. 用键盘 `Q..U`、`A..J`、`Z..M` 弹奏，音符自动记录
3. 加几个 `|` 分隔乐句，`Enter` 换行
4. 点 **▶ 播放** 回放，用延迟滑块调速
5. 点选音符编辑修正，最后**导出 JSON** 保存谱面
6. 对照谱面去游戏琴上弹奏

## ⌨️ 快捷键

| 按键 | 功能 |
|------|------|
| `Q..U` / `A..J` / `Z..M` | 弹奏高/中/低音（可自定义） |
| `Backspace` | 退格（删除最后一个音符） |
| `Enter` | 换行 |
| `空格` | 插入 `|` 分隔符 |

---

## ⚙️ 配置说明

以下参数可在源码中调整：

| 参数 | 位置 | 说明 |
|------|------|------|
| `CHORD_WINDOW` | 顶部常量 | 和弦判定时间窗口（默认 80ms），改小更难触发和弦、改大更容易 |
| `TONES` | 声音区 | 音色预设（温暖/柔和/明亮），可调泛音、亮度、衰减 |

---

## 📌 小贴士
- 页面需**处于焦点**才能用物理键盘记录
- 首次使用需一次点击解锁声音（浏览器安全策略）
- 和弦判定窗口默认 80ms，可在源码 `CHORD_WINDOW` 调整灵敏度
